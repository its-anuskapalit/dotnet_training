**Scenario 1: Banking System**

**Problem Statement:** Design a simple banking system with the following features:

1. Create account with account number, holder name, and initial balance

2. Deposit money

3. Withdraw money (with validation - cannot withdraw more than balance)

4. Transfer money between accounts

5. Calculate interest (simple interest)

6. Display account statement (last 5 transactions)

// Interface you need to implement
public interface IBankAccount {
    void Deposit(decimal amount);
    bool Withdraw(decimal amount);
    bool Transfer(IBankAccount toAccount, decimal amount);
    decimal CalculateInterest(int years);
    List<string> GetMiniStatement();
    decimal GetBalance();
}

// Example usage:
BankAccount account1 = new BankAccount("ACC001", "John Doe", 1000);
BankAccount account2 = new BankAccount("ACC002", "Jane Smith", 500);

account1.Deposit(500);
account1.Withdraw(200);
account1.Transfer(account2, 300);

Console.WriteLine($"Account1 Balance: {account1.GetBalance()}");
Console.WriteLine($"Account2 Balance: {account2.GetBalance()}");

// Expected output format for mini-statement:
// [1] Deposit: +500 | Balance: 1500
// [2] Withdraw: -200 | Balance: 1300
// [3] Transfer to ACC002: -300 | Balance: 1000

**Scenario 2: E-commerce Shopping Cart**

**Problem Statement:** Implement a shopping cart system for an e-commerce platform with:

1. Add product to cart with quantity

2. Remove product from cart

3. Update product quantity

4. Apply discount codes

5. Calculate total with tax (18% GST)

6. Checkout functionality with inventory validation

7. Generate invoice

public class Product {
    public string Id { get; }
    public string Name { get; }
    public decimal Price { get; }
    public int Stock { get; set; }
}

public class ShoppingCart {
    public void AddProduct(Product product, int quantity);
    public void RemoveProduct(string productId);
    public void UpdateQuantity(string productId, int newQuantity);
    public bool ApplyDiscount(string discountCode);
    public decimal CalculateTotal();
    public bool Checkout();
    public string GenerateInvoice();
}

// Business Rules:
// - Cannot add more than available stock
// - Discount codes: "SAVE10" gives 10% off, "SAVE20" gives 20% off
// - Tax is 18% on subtotal (after discount)
// - Minimum order amount: 100
// - Checkout fails if any product has insufficient stock

**Scenario 4: Hotel Booking System**

**Problem Statement:** Implement a hotel room booking system with:

1. Room types: Single, Double, Suite

2. Booking dates validation (no overlapping bookings)

3. Calculate price based on room type and duration

4. Apply seasonal rates (peak season: 20% extra)

5. Cancel booking with refund policy

public class Room {
    public string RoomNumber { get; }
    public RoomType Type { get; }
    public decimal BasePrice { get; }
    public bool IsAvailable(DateTime from, DateTime to);
}

public class Booking {
    public string BookingId { get; }
    public Room Room { get; }
    public DateTime CheckInDate { get; }
    public DateTime CheckOutDate { get; }
    public decimal TotalPrice { get; }
    
    public decimal CalculatePrice(bool isPeakSeason);
    public decimal CalculateRefund(DateTime cancellationDate);
}

// Business Rules:
// - Peak season: June 1 - Aug 31 (20% extra)
// - Cancellation refund:
//   - > 7 days before check-in: 100% refund
//   - 3-7 days before: 50% refund
//   - < 3 days: No refund
// - Minimum stay: 1 night
// - Maximum stay: 30 nights

**Scenario 5: Log File Analyzer**

**Problem Statement:** Parse server log files and generate reports:

1. Count total requests per endpoint

2. Find most frequent IP addresses

3. Identify errors (status code >= 400)

4. Calculate average response time

5. Generate hourly traffic report

// Log format: 
// [Timestamp] [IP] [Method] [Endpoint] [Status] [ResponseTime]
// Example: "2024-01-15 10:30:45 192.168.1.1 GET /api/users 200 150ms"

public class LogEntry {
    public DateTime Timestamp { get; }
    public string IPAddress { get; }
    public string Method { get; }
    public string Endpoint { get; }
    public int StatusCode { get; }
    public int ResponseTimeMs { get; }
}

public class LogAnalyzer {
    public Dictionary<string, int> GetRequestsPerEndpoint(List<LogEntry> logs);
    public List<string> GetTopIPs(List<LogEntry> logs, int topN);
    public Dictionary<int, int> GetErrorCounts(List<LogEntry> logs);
    public Dictionary<int, double> GetHourlyTraffic(List<LogEntry> logs);
    public Dictionary<string, double> GetAverageResponseTimePerEndpoint(List<LogEntry> logs);
}

// Additional Requirements:
// - Filter logs by date range
// - Find slowest endpoints (response time > 500ms)
// - Detect potential attacks (same IP making > 100 requests/minute)

**Scenario 10: File System Watcher**

**Problem Statement:** Create a file monitoring system that:

1. Watches directory for changes

2. Logs file creation, modification, deletion

3. Filters by file type

4. Maintains file version history

5. Sends notifications

public class FileChange {
    public string FilePath { get; }
    public ChangeType Type { get; }
    public DateTime Timestamp { get; }
    public string OldContent { get; } // For modifications
    public string NewContent { get; }
}

public enum ChangeType { Created, Modified, Deleted, Renamed }

public class FileMonitor {
    public void WatchDirectory(string path, List<string> extensions);
    public void StopWatching();
    public List<FileChange> GetRecentChanges(int minutes);
    public void BackupFile(string filePath);
    public void RestoreVersion(string filePath, DateTime versionTime);
    
    // Event to notify changes
    public event EventHandler<FileChange> OnFileChanged;
}

// Features:
// - Monitor .txt, .csv, .json files only
// - Keep last 5 versions of each file
// - Ignore changes smaller than 1KB
// - Log all activities to database
// - Send email alert for critical file changes
